## 1. 서비스 개요

### 1-1. 한 줄 정의
고객이 촬영 목적과 상황에 맞는 사진작가를 질문형 네비게이터로 찾고, 예약부터 결제·소통·결과물 전달까지 플랫폼 안에서 완결하는 사진 촬영 매칭 서비스.

### 1-2. 문제 정의
- 고객은 어떤 작가가 자신의 촬영(행사/가족/커플/여행 등)에 적합한지 판단하기 어렵다.
- 기존 방식(블로그, 인스타그램 DM 등)은 가격 비교가 어렵고, 예약·정산·분쟁 기록이 남지 않는다.
- 카카오톡 등 외부 채널로 소통이 빠지면 플랫폼이 거래를 중개·보증할 수 없다.

### 1-3. 핵심 원칙
- 최저가 순이 아닌 **적합도 기반 추천** (촬영 분야, 분위기, 일정, 지역, 후기 종합)
- 예약 생성 시점부터 **전용 소통방**으로 모든 대화·합의를 플랫폼 내부에 기록
- 결제 전에는 **연락처 비공개**, 예약금 결제 후 공개 — 플랫폼 이탈 방지
- 결과물 전달, 수정 요청, 후기까지 **거래 전 과정을 플랫폼 안에서 종결**
- **거래구조**: 사진작가가 촬영 서비스의 판매자, 플랫폼은 통신판매중개자 — 결제·정산·고객상담은 플랫폼이 전담하되, 촬영 이행·품질 책임은 작가에게 귀속 (상세 4장)

## 2. 핵심 사용자 플로우

### 2-1. 고객 플로우 (촬영 네비게이터)
1. **촬영 종류 선택**: 행사 / 기념일 / 커플 / 가족 / 외국인 한국 여행 촬영 / 여행 동행 촬영 / **시니어 투어**
   - ⚠️ 촬영 종류는 향후 지속 확장 예정 — DB·UI 모두 하드코딩 나열이 아닌 **설정 가능한 카테고리 목록**으로 설계
2. **세부 상황 선택**: (예: 행사 → 기업 포럼, 세미나, 시상식, 공연, 체육행사, 교회·학교·단체행사, 보도자료)
3. **분위기 선택**: 밝고 화사 / 자연스럽고 생생 / 전문적이고 정돈 / 따뜻하고 감성적 / 고급스럽고 차분 / 시네마틱
4. **촬영 조건 입력**: 날짜, 지역, 시간, 인원, 예산, 사용 목적, 결과물 필요일, 필수 장면, 플래시 가능 여부, 외국어 소통 필요 여부
5. **작가 추천**: 분야 적합도·포트폴리오 분위기·일정·활동 지역·경험·후기·납품 가능일·예산 범위 종합 매칭

### 2-2. 예약~정산 플로우
```
문의 접수 → 작가 수락 → 견적 확정 → 예약금 결제(20~30%)
→ 전용 소통방 개설 → 촬영 정보 확정(버튼 확정) → 잔금 결제
→ 촬영 완료(작가 상태 변경) → 사진 납품(업로드) → 고객 확인
→ 후기 작성 → 작가 정산(수수료 차감 후 지급)
```

### 2-3. 연락처 공개 시점
| 단계 | 연락처 상태 |
|---|---|
| 결제 전 | 비공개, 플랫폼 채팅만 가능, 개인정보 포함 메시지 자동 경고 |
| 예약금 결제 후 | 상호 공개, 긴급 연락 버튼 제공, 통화 후 변경사항은 소통방에 재기록 |

## 3. 기능 요구사항

### 3-1. 작가 프로필 & 포트폴리오
- 기본 정보: 소개, 전문 분야, 활동 지역, 경력, 분위기 태그
- 촬영 패키지: 기본가, 추가비용, 촬영시간, 제공 사진 수, 보정 범위, 원본 제공 여부, 납품 기간, 장비, 조명/플래시, 외국어 가능 여부, 예약 가능 일정
- 실제 예약 고객 후기 (연동, 별도 작성 불가)
- 포트폴리오 카테고리 분리: 행사 / 가족 / 커플 / 여행 스냅 / 공연·스포츠 / 프로필 / 브랜드

### 3-2. 예약별 전용 소통방
- 기본 채팅 (메시지, 파일·이미지 첨부, 참고 이미지, 행사 식순 공유, 위치 지도 공유, 읽음 표시)
- 촬영 정보 패널: 촬영일/시간/장소/집합장소/인원/담당자/목적/필수 장면/납품일
- 촬영 체크리스트 (행사 촬영 예: 전경, 현수막·로고, 주요 내빈, 발표자, 참석자 반응, 네트워킹, 단체사진, 보도자료용)
- 일정 변경 요청 → 상대방 승인 흐름
- **중요 내용 확정 버튼**: 최종 촬영일/장소/시간/금액/추가요청/납품예정일 — 일반 채팅과 분리하여 기록

### 3-3. 일정 관리
- 작가 상태: 촬영 가능 / 상담 중 / 예약 대기 / 예약 확정 / 촬영 완료 / 휴무 / 이동 불가 시간
- **일정 충돌 방지**: 동일 시간대 이중 수락 차단
  - ⚠️ 보완 필요: 문의~결제 완료 사이 슬롯을 언제 "홀드"할지 정책 필요 (예: 견적 확정 시점부터 30분~1시간 임시 홀드, 미결제 시 자동 해제)
- 알림: 문의 접수 → 수락 → 결제 요청 → 결제 완료 → D-7 → D-1 → 당일 → 납품 예정일 → 납품 완료 (초기 이메일/사이트 알림, 이후 카카오 알림톡 확장)
- 향후: Google Calendar 연동으로 이중 예약 방지

### 3-4. 견적 및 상품 구조
- 기본 패키지(행사 베이직/프리미엄, 여행 스냅 등) + 맞춤 견적 병행
- 추가 옵션: 시간 연장, 작가 2인, 당일 제공, 정밀 보정, 원본 제공, 출장비, 야간, 드론, 영상, 앨범/인화

### 3-5. 결제 (토스페이먼츠 연동, 에스크로형)
- 1단계 예약금 → 2단계 잔금 → 3단계 촬영완료 → 4단계 납품 → 5단계 고객확인 → 6단계 작가 정산
- 결제는 플랫폼이 직접 수령(에스크로형) — 고객 결제창에는 판매자로 작가 정보가 표시되지만, 대금 수령·환불 처리는 플랫폼이 수행
- 웹훅으로 결제완료/취소/만료를 주문 상태에 반영
- ⚠️ 보완 필요: **PG 정산 주기(T+N일)와 작가 정산일이 다르므로 정산 대사(reconciliation) 로직** 필요

**확정 정책 (초안, 세부 숫자는 운영 데이터로 조정 가능)**

| 항목 | 확정안 |
|---|---|
| 예약금 비율 | 30% |
| 잔금 결제 기한 | 촬영 3일 전 |
| 플랫폼 수수료 | 15~20% |
| PG 결제수수료 부담 | 작가 정산금에서 차감 |
| 슬롯 홀드 | 작가 견적 확정 후 1시간 임시 홀드, 미결제 시 자동 해제 |

**취소·환불 — 고객 귀책** (소비자분쟁해결기준 사진촬영업 조항 참고: 촬영 개시 전 고객 귀책 해지는 총요금의 10%가 기준점)

| 취소 시점 | 처리 |
|---|---|
| 작가 확정 전 | 전액 환불 |
| 결제 후 24시간 이내 & D-7 이전 | 전액 환불 |
| 촬영 개시 전 | 총 촬영금액의 10% 부담 |
| 당일 취소·노쇼 | 총 촬영금액의 10% + 고객 동의 하에 실제 발생한 회수 불가 비용(스튜디오 대관료, 입장권, 교통·숙박 예약비, 장비 대여비, 취소불가 외부 인력비 등만 인정) |
| 촬영 개시 후 | 이미 제공된 촬영비 + 잔여금액의 10% |

**취소·환불 — 작가 귀책** (실질 부담은 작가, 플랫폼은 선지급 후 작가 정산금에서 차감)

| 상황 | 처리 |
|---|---|
| 촬영 개시 전 작가 취소 | 전액 환불 + 총 금액의 10% 보상 |
| 촬영 당일 취소·노쇼 | 전액 환불 + 총 금액의 10% 보상 + 대체 작가 우선 탐색 지원 |
| 촬영 후 파일 멸실 | 계약금 환급 및 손해배상 심사 |
| 일부 결과물 문제 | 재보정 / 부분 환불 / 재촬영 중 조정 (관리자 심사) |

⚠️ 과거 검토했던 "당일 취소 70%" 안은 약관법상 고객에게 과중한 손해배상을 지우는 조항으로 무효 판단 위험이 있어 **10%+실비 기준으로 하향 확정**. 우천·천재지변(야외 촬영)은 무료 일정변경 1회 허용 후, 재변경 불가 시 위 기준에 준해 협의 처리.

⚠️ 오픈 전 **전자상거래 전문 변호사에게 약관 검토** 필요 (취소수수료 조항의 유효성 확인).

### 3-6. 작가 정산

**정산 대상: 1차 오픈은 사업자등록 작가만.** 개인(비사업자) 작가는 포트폴리오 등록·작가 지원 신청까지만 가능, 유료 예약 활동은 사업자 인증 후 개방. (이유: 3.3% 원천징수 판단·원천세 신고·간이지급명세서 제출 등 세무 부담을 초기부터 지지 않기 위함. 개인 작가 확대는 2차 과제로 별도 세무 구조 설계 후 진행)

- 등록 정보: 본인인증(휴대전화/이메일), 정산계좌(예금주), 사업자등록번호·대표자명, 활동 지역 — 토스페이먼츠 지급대행 KYC 요구사항과 동일 선상에서 수집
- 정산 계산식: `고객 결제금액 − 취소·환불금 − 플랫폼 중개수수료 − 작가 부담 추가비용 = 작가 정산금` (예: 결제 50만 원, 수수료 15% → 정산금 42.5만 원)
- 정산명세서 제공 항목: 결제금액, 예약금, 잔금, 환불금, 플랫폼 수수료, 작가 귀책 보상금, 정산 예정금액, 정산 완료금액, 지급일
- 정산 시점: 고객 사진 확인(또는 납품 후 7일 이내 미확인 시 자동 확인) + 3영업일 후, **매주 1회 정기 정산**
- **신규 작가 특례**: 첫 3건은 촬영 완료 후 7일간 정산 유보, 분쟁 없으면 지급 → 이후 일반 정산 주기로 전환
- **정산 보호 권한** (작가 이용약관에 명시): 고객 분쟁 발생 시 정산 보류 / 작가 귀책 환불금·보상금·차지백 금액을 정산금에서 공제·상계 / 정산금 부족 시 청구일로부터 7일 이내 작가가 부족액 지급 / 작가 탈퇴 후에도 미해결 채무 존속
- 세금계산서 또는 현금영수증 발행 흐름 (사업자 작가 전제이므로 3.3% 원천징수·지급명세서 이슈는 1차 범위 밖)
- 결제 수수료는 작가 정산금에서 차감

⚠️ **PG 계약 전 세무사에게 "오픈마켓 중개매출·셀러 정산 구조"로 매출 귀속 방식 확인 필요.**

### 3-7. 전자 계약 및 촬영 동의
- 계약 항목: 일시/장소, 촬영범위, 금액, 제공 사진 수, 보정 범위, 납품기한, 원본 제공, 취소·환불, 일정변경, 지각·노쇼, 사고 대응, 초상권, 저작권, 포트폴리오 사용 동의, 개인정보
- **포트폴리오 공개 동의는 별도**: 공개 동의 / 일부 공개 / 얼굴 비공개 조건 / 미동의
- ⚠️ 보완 필요: **미성년자가 피사체로 포함되는 경우(가족사진, 행사 촬영 내 아동 등) 보호자 대리 동의 플로우**가 실제 기능 설계에 명시되어야 함

### 3-8. 사진 전달
- 대표사진 미리보기, 전체 갤러리, 일괄/개별 다운로드, 모바일 공유, 다운로드 만료일, 추가 보정 요청, 납품 확인, 후기 작성
- 저장 정책: 납품 후 30일 다운로드, 7일 전 만료 알림, 연장 유료 옵션, 원본 별도 유료 보관, 만료 후 자동 삭제
- 별도 클라우드 스토리지 사용 권장
- ⚠️ 보완 필요: **해외 리전 클라우드 사용 시 개인정보 국외이전 고지·동의**를 개인정보처리방침에 명시

### 3-9. 수정 요청
- 사진 번호 선택 → 수정 내용(피부보정/밝기색감/수평크롭/배경정리/안경반사/정밀보정) → 완료 여부
- 기본 수정 횟수 및 추가 비용 기준을 상품에 명시

### 3-10. 후기
- 실제 결제·촬영 완료 고객만 작성 가능
- 항목: 사진 만족도, 친절함, 시간 준수, 소통, 현장 진행, 납품 속도, 재이용 의향
- 촬영 분야별(행사/아이/외국인/여행 동행) 후기 분리 노출

### 3-11. 고객센터 및 분쟁 처리
- 메뉴: FAQ, 1:1 문의, 결제 문의, 예약 변경, 취소·환불, 작가 신고, 결과물 분쟁, 사진 삭제 요청, 개인정보 문의, 제휴 문의
- **긴급 문의 별도 채널** (촬영 전날/당일): 작가 미연락, 고객 노쇼, 장소 급변경, 기상 문제
- **분쟁 제기 화면(취소 화면과 별도 UI)**: 취소는 촬영 "전" 일정·환불 처리이고, 분쟁 신고는 촬영 "후" 결과물·이행 문제를 다룸 — 진입점을 분리해서 예약 상세/소통방 양쪽에 각각 노출
  - 대상 예약 선택 → 신고 유형(사진품질/노쇼·지각/납품지연/계약조건 미이행/기타) → 상세내용+증빙 첨부(소통방 대화 자동 첨부) → 접수
  - 접수 즉시 해당 예약 정산 자동 보류, 진행상태 4단계(접수→작가 사실확인 요청 24h→관리자 조정→해결) 고객·작가 양쪽에 실시간 노출

### 3-12. 작가 검증
- **가입 조건(확정)**: 유료 촬영상품을 등록하고 예약을 받으려면 본인 또는 소속 사업체 명의의 유효한 사업자등록 필수. 비사업자 개인은 포트폴리오 등록·지원 신청만 가능
- 가입: 휴대전화 인증, 신분 확인, 사업자 확인, 정산계좌 인증, 포트폴리오 제출, 전문 분야, 장비·지역 등록, 계약·운영정책 동의
- 운영: 취소율, 응답 속도, 납품 준수율, 만족도, 분쟁 건수, 재예약률
- 별점 단일 지표보다 **분야별 강점 노출** 지향

### 3-13. 관리자 페이지
- 대시보드: 신규 고객/작가, 촬영 문의, 예약 대기, 결제 완료, 촬영 예정, 납품 지연, 환불 요청, 분쟁 건, 정산 예정, 월 거래액, 플랫폼 수익

## 4. 법적·정책 요건

### 4-1. 거래구조 (확정)

| 역할 | 주체 | 책임 범위 |
|---|---|---|
| 촬영 서비스 판매자 | 사진작가 | 촬영 일정 준수, 서비스 이행, 결과물 품질, 보정·납품, 작가 귀책 취소, 사진 멸실·훼손, 초상권·저작권 준수, 작가의 세금 신고 |
| 통신판매중개자 | 플랫폼 | 작가 탐색·추천, 예약·일정 관리, 결제(에스크로), 작가 정산, 소통방 운영, 고객 문의 접수, 취소·환불 접수, 분쟁 사실관계 확인, 정산 보류, 환불·보상금 지급대행, 문제 작가 이용정지 |

- 촬영계약은 **고객 ↔ 작가** 사이에 체결되며, 플랫폼은 계약 당사자가 아님
- 고객상담·고객센터는 **플랫폼이 전담** (작가에게 직접 문의하게 하지 않음) — 단, "플랫폼이 결과를 책임진다"가 아니라 "플랫폼이 절차를 지원·중재한다"는 표현만 사용
  - 사용 가능 표현: "플랫폼이 끝까지 처리 절차를 지원합니다", "작가 정산을 보류하고 환불을 대행합니다", "문제가 발생하면 중재합니다"
  - 금지 표현: "촬영 품질을 100% 보장합니다", "모든 손해를 플랫폼이 배상합니다", "소속 작가가 직접 촬영합니다"
- **플랫폼 직접 책임 범위(면책 제외 대상)**: 플랫폼 결제 오류, 시스템 오류로 인한 중복예약, 잘못된 작가정보 제공, 개인정보 유출, 직원의 고의·과실, 약속한 환불처리의 부당한 지연
- **작가 책임 범위**: 지각·노쇼, 촬영 누락, 사진 품질, 장비 고장, 파일 멸실, 보정·납품 지연, 저작권·초상권 침해, 확정된 촬영조건 미이행

### 4-2. 결제 화면·예약확정서 필수 표시 정보
| 구분 | 항목 |
|---|---|
| 촬영 서비스 제공자(작가) | 작가명/상호, 대표자명, 사업자등록번호, 연락처, 이메일, 활동 지역 |
| 플랫폼 운영자 | 회사명, 사업자등록번호, 대표자, 고객센터, 대표 이메일, 통신판매 신고정보 |

⚠️ 이 신원정보 고지·제공을 누락하거나 사실과 다르게 제공하면 **중개 플랫폼에도 손해배상 책임 발생 가능** — 결제 전(청약 전) 필수 노출.

### 4-3. 필수 정책 페이지
서비스 이용약관 / 개인정보처리방침 / 예약·취소·환불 정책 / 작가 이용약관(정산 보호 권한 조항 포함) / 작가 정산 정책 / 위치정보·지도 서비스 안내 / 마케팅 정보 수신 동의 / 개인정보 제3자 제공 동의 / 개인정보 처리 위탁 안내 / 초상권·저작권 정책 / 분쟁 처리 정책 / 청소년·미성년자 촬영 동의 / **통신판매중개자 고지**

### 4-4. 사이트 게재용 확정 문구 (초안)
> 본 플랫폼은 고객과 사진작가 사이의 촬영 서비스 거래를 연결하는 통신판매중개 서비스입니다. 촬영 서비스의 실제 판매자 및 제공자는 각 상품과 결제화면에 표시된 사진작가이며, 촬영 일정 준수, 현장 촬영, 결과물의 품질, 보정 및 납품 등 촬영계약의 이행 책임은 해당 사진작가에게 있습니다. 플랫폼은 작가 탐색, 예약, 결제, 정산, 일정관리, 고객과 작가 간 소통, 고객 문의 및 분쟁처리 서비스를 제공합니다. 고객은 모든 문의와 불만을 플랫폼 고객센터를 통해 접수할 수 있으며, 플랫폼은 운영정책에 따라 사실관계를 확인하고 작가 정산 보류, 환불, 재촬영, 부분 보상 또는 기타 필요한 조치를 중재합니다. 플랫폼의 고의 또는 과실로 발생한 손해 및 관계 법령에 따라 플랫폼이 부담해야 하는 책임은 제한되지 않습니다.

- 작가는 플랫폼의 사실확인 요청 접수 후 **24시간 이내 답변 의무**, 지연 시 정산 보류 가능
- 환불·보상 처리 문구, 고객센터 안내 문구는 위와 동일 톤으로 별도 페이지 구성 필요

⚠️ **오픈 전 필수**: 전자상거래 전문 변호사에게 이용약관 검토, 세무사에게 작가 매출·플랫폼 수수료·영수증·정산 구조 검토.

## 7. 확정 사항 및 남은 리스크

### 7-1. 확정된 사항
| 구분 | 확정 내용 |
|---|---|
| 거래구조 | 작가=판매자, 플랫폼=통신판매중개자 (에스크로형 결제) |
